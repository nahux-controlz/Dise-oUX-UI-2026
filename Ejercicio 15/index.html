Justificación del Enfoque: Se optó por un enfoque Mobile First. Escribir el CSS base para celulares garantiza que los dispositivos móviles (que tienen menos potencia de procesamiento) no tengan que cargar estilos complejos de escritorio para luego sobrescribirlos. Las media queries (min-width) solo añaden la estructura del Grid avanzado cuando la pantalla es lo suficientemente grande.
