Descripción

Este repositorio contiene la resolución de los 20 ejercicios del Trabajo Práctico de HTML y CSS, estructurados en carpetas individuales desde el nivel básico hasta el integrador avanzado.
Decisiones de Diseño Relevantes

    Enfoque Responsivo: Se adoptó una estrategia Mobile First en los ejercicios de Media Queries (ej. 15 y 20) para priorizar el rendimiento en dispositivos móviles.

    Estructura y Semántica: Se utilizaron etiquetas HTML5 semánticas (header, main, section, footer) para optimizar la accesibilidad y el SEO.

    Layout Avanzado: Se combinó Flexbox para alineaciones unidimensionales y CSS Grid con grid-auto-flow dense para resolver distribuciones asimétricas complejas sin dejar espacios vacíos.

    Lógica en CSS Puro: Los estados interactivos, como el menú hamburguesa y el formulario multi-step, se resolvieron exclusivamente con CSS utilizando pseudo-clases y selectores de hermanos.
